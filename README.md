# Office Network Design — Cisco Packet Tracer

## Project Overview
Multi-department enterprise office network designed 
using Cisco Packet Tracer.

## Features Implemented
-  VLANs (Management, HR, Finance, IT, Sales)
-  Inter-VLAN Routing (Layer 3 Switch)
-  DHCP Server Configuration
-  Dual Router Setup (ISP + Office)
-  NAT/PAT for Internet Access
-  DNS + Web Server
-  SSH Remote Access
-  ACL Security Policies

## Network Topology
- 1x Layer 3 Core Switch
- 5x Department Switches
- 2x Routers (ISP + Office)
- 1x DNS/Web Server

## VLAN Structure
| VLAN | Department | Network |
|------|-----------|---------|
| 10 | Management | 192.168.10.0/24 |
| 20 | HR | 192.168.20.0/24 |
| 30 | Finance | 192.168.30.0/24 |
| 40 | IT | 192.168.40.0/24 |
| 50 | Sales | 192.168.50.0/24 |

## Tools Used
- Cisco Packet Tracer
- Cisco IOS CLI

## Skills Demonstrated
- Network Design & Implementation
- VLAN Configuration & Trunking
- Layer 3 Switching & Routing
- NAT/PAT Configuration
